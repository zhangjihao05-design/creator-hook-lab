# Hook Lab

An agentic website where a hook editor, a hook writer and a hook critic write, score and rank opening hooks and titles for a video or post. Creator Agent Studio calls it on every run, and Hook Lab can call Creator Agent Studio back.

- Live site: https://creator-hook-lab.pages.dev/
- Agent network: https://creator-hook-lab.pages.dev/hook_lab.network.json
- Partner site: Creator Agent Studio, https://creator-agent-studio.pages.dev/ (source: https://github.com/zhangjihao05-design/creator-agent-studio)
